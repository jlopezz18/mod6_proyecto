# Proyecto mod6 - Web desployment

## URL de la aplicacion
[https://mod6-proyecto.vercel.app/]

## Descripcion
Esta aplicacion esta desarrollada con React para demostrar la config y ejecucion de un flujo de despliegue continuo

## Instrucciones de Despliegue
Para clonar y ejecutar este proyecto se debe:
1. Clonar el repositorio: `git clone [https://github.com/jlopezz18/mod6_proyecto]`
2. Entrar al directorio: `cd [mod6_proyecto]`
3. Instalar las dependencias: `npm install`
4. Levantar el servidor: `npm start`
